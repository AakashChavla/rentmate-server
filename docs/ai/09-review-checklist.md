# Review checklist

- Observe both verify:quick commands passing; identify infrastructure suites not yet implemented.
- Check abstraction ports, module/feature public APIs, layer directions and no cycles.
- Check strict typing, meaningful constants, files/functions/complexity limits and translated strings.
- Check locale key parity, ICU placeholders, unused keys and Hindi human review notes.
- Check API schema/client types agree, request IDs, envelopes and health exceptions.
- Check security redaction, CSP nonce, same-origin cookie rules and absence of secrets.
- Check accessible labels, keyboard behavior, contrast, reduced motion and responsive layout.
- Record decisions, proof diagnostics, command outcomes and remaining work before the phase commit.
